# Журнал изменений

## 1.0.0 — 2026-07-21

- проект полностью переименован в File Atelier;
- добавлены устанавливаемый пакет и команда `file-atelier`;
- предпросмотр сделан безопасным режимом по умолчанию, применение требует `--apply`;
- добавлены полный план, явный рекурсивный режим и итоговая сводка;
- исключена перезапись файлов, включая конфликт, появившийся после планирования;
- добавлена строгая проверка JSON-конфигурации и защита границ исходного каталога;
- удалена неиспользуемая заготовка GUI, документация приведена к фактической архитектуре;
- обновлены целевые тесты, Ruff и GitHub Actions.
