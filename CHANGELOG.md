# Журнал изменений

## 1.1.0 — 2026-07-21

- добавлен настольный интерфейс на `tkinter` и `ttk` в светлом стиле CodeVinci;
- добавлены команды `file-atelier-gui` и `python -m file_atelier.gui`;
- GUI использует общие конфигурацию, планирование и выполнение без отдельной сортировки;
- изменение каталога, конфигурации или рекурсивного режима инвалидирует старый план;
- таблица показывает категории, назначения, статусы и конфликты имён;
- добавлена воспроизводимая onefile-сборка PyInstaller для Windows;
- добавлен ручной workflow сборки Windows-артефакта.

## 1.0.0 — 2026-07-21

- проект полностью переименован в File Atelier;
- добавлены устанавливаемый пакет и команда `file-atelier`;
- предпросмотр сделан безопасным режимом по умолчанию, применение требует `--apply`;
- добавлены полный план, явный рекурсивный режим и итоговая сводка;
- исключена перезапись файлов, включая конфликт, появившийся после планирования;
- добавлена строгая проверка JSON-конфигурации и защита границ исходного каталога;
- удалена неиспользуемая заготовка GUI, документация приведена к фактической архитектуре;
- обновлены целевые тесты, Ruff и GitHub Actions.
