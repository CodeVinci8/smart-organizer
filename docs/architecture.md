# Архитектура проекта Smart Organiser

## Основная идея
Приложение заточено будет под удобную и автоматическую сортировку файлов, что-то по типу
проводника

## Основные классы
- File
- FileManager
- GUI

## Связи
- FileManager содержит список файлов:
file: list[File]
- GUI использует FileManager для отображения данных

## Пример структуры 
[GUI] ---> [FileManager] ---> [Task]
